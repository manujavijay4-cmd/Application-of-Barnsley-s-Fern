***Barnsley’s Fern – Linear Algebra & IFS Project***

This project explores Barnsley’s Fern, a fractal generated using an Iterated Function System (IFS).
Using four affine transformations (matrix + translation) and their associated probabilities, the Python program repeatedly applies these transformations to produce the classic fern shape. This demonstrates how linear algebra and probabilistic iteration create complex natural patterns.
Contents


barnsley_fern.py – Python code to generate the fern, histograms, and Chi-square analysis

Barnsley_Fern_Presentation.pptx – Project presentation

Barnsley_Fern_Report.pdf – Full written report

***What the Project Does***


1.Implements the four IFS transformations from Barnsley’s fern

2.Generates fractal images for various iteration counts

3.Analyzes how often each transformation is used

4.Performs a Chi-square goodness-of-fit test

5.Visualizes the distribution of points (x and y histograms)


***How to Run***
pip install numpy matplotlib scipy
python barnsley_fern.py

***Summary***
This project shows how simple linear transformations can create complex fractal structures. It connects linear algebra, probability, and fractal geometry through visualization and statistical analysis.
